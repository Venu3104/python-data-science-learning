A practical project applying NumPy concepts to analyze student marks.

### Features

- Calculate mean, median, minimum, and maximum marks

- Calculate standard deviation
- Reshape arrays and calculate row-wise averages

- Create modified copies of arrays without changing the original data
- Save and load arrays for later use

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Venu3104/python-data-science-learning.git
cd python-data-science-learning
```



### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install NumPy

```bash
python -m pip install numpy
```

### 4. Run a lesson

```bash
python Numpy/lesson1.py
```

Change the filename to run a different lesson or exercise.
